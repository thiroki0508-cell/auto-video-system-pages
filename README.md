# Auto Video System — public documentation

English application information, Privacy Policy, and Terms of Service for a private personal Windows desktop application.

This repository contains only static documentation. It does not distribute the desktop app, its private source, credentials, research records, or data.

## Pages

- `index.html` — application overview and current limitations
- `privacy.html` — actual processing, local storage, retention, deletion, and provider disclosures
- `terms.html` — personal use, third-party services, rights, and limitations
- `styles.css` — shared responsive styles; no external dependencies

Publish using GitHub Pages from the `main` branch, repository root (`/`). `.nojekyll` disables Jekyll processing. There are no custom workflows, JavaScript, trackers, external fonts, or build dependencies.

General documentation and privacy questions: use this repository's Issues. Issues are public; never post credentials, personal information, or private app data.

Updated October 14, 2026. Publication does not imply Google or YouTube approval or provide access to the desktop application.
