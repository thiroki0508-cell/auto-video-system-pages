Application overview / Windows desktop

Research public videos.
Plan original content.

Auto Video System is a personal Windows desktop application developed by an individual developer in Japan. It helps its owner research public YouTube information, organize candidates, and consider the work involved in original video ideas.

This website is informational. The desktop application is private and used by its owner. This site provides no public login, hosted application, or desktop download.

Current features

From public information to a personal research workspace

01 / Discover

Search across topics

Search public videos manually or start discovery with keywords selected from a local genre catalog. Set a publication period, search order, result limit, and search-request budget.

02 / Review

Keep useful candidates

Browse thumbnails, titles, channel names, publication dates, view counts, durations, video IDs, and YouTube links. Keep or discard candidates, filter the list, and compare saved records during research.

03 / Plan

Consider your own production

Add review notes and production-format assumptions. Estimate the owner's proposed production costs from manually entered fees, time, and labor rates. These are planning assumptions, not a source video's actual costs or earnings.

Independent value

A workspace for decisions and original ideas

The app adds candidate organization, personal annotations, production-format hypotheses, and the owner's own cost assumptions to a public-metadata research workflow. The owner decides what to investigate and what original content to create.

References are starting points for research. The app does not download, copy, or republish other people's videos.

Analysis has clear limits

Current local tools use explicit word-matching rules and basic thumbnail image measurements to suggest review groups and production hypotheses. Optional description retrieval supports limited text checks.

These tools do not watch or understand the full video, establish demand, measure click-through rate, prove production suitability, or estimate actual advertising revenue. Human review remains necessary.

Development status

Optional planning and unavailable features

An optional, developing OpenAI original-topic planner can send an owner-entered topic and planning instructions to OpenAI using a separate key. It can save structured outline and production-instruction drafts locally. It does not read or send the app's YouTube video records; the owner must also avoid entering copied API data, secrets, or personal information as a topic. See the OpenAI disclosure.

The broader analysis and selection workflow is still under development. Independent numerical popularity scores, views-per-day or growth metrics, cross-channel performance scoring, and revenue predictions are not enabled. Automatic video production, media generation, downloading, and uploading are not implemented. No Google or YouTube approval is claimed by this website.

External services

YouTube API Services

The desktop app uses YouTube Data API v3 to retrieve public metadata and connects to YouTube image servers for thumbnails. Opening a video link takes the owner to YouTube in their browser. The app currently uses an API key, not YouTube account sign-in or OAuth access to private account data.
